# Geradis site
Хотелось бы в стиле панк-рок, но надо соблюдать приличие.

Полностью автономный: без сборки, без внешних CDN — все шрифты и
изображения лежат в `assets/`. (архитектура устарела??)

## Структура (схема устарела??)

```
├── index.html            # страница (весь CSS и JS внутри)
├── favicon.ico           # иконка сайта
├── .nojekyll             # отключает Jekyll на GitHub Pages
├── README.md             # этот файл
└── assets/
    ├── fonts/            # DM Sans, Libre Baskerville, Caveat (woff2)
    └── img/              # стол, салфетка, иконки, og-image
```
